# Spendwise

Personal expenditure tracker built with React + Vite.

## Current status

- Mobile-responsive React app source is being added.
- Private data repository: [spendwise-data](https://github.com/vishwashyadav/spendwise-data) (private).
- Data schema initialized at `data/spendwise.json`.
- Production hosting and OAuth gateway setup are separate deployment steps; do not store GitHub tokens in frontend code.

## Local development

```bash
npm install
npm run dev
```

See the setup guide for Cloudflare Pages Functions and OAuth before enabling cross-device sync.
